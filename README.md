# Library Management System

A simple terminal-based Library Management System built with Python using Object -Oriented Programing (OOP) principles.

## Features
- Add new books to the library.
- Register new users.
- Borrow books (checks if the book and user exist).
- Return books (checks if the user actually borrowed the book).

## Concepts Practiced
- Classes and Objects ("Book" , "User" , "Library").
- Encapsulation (managing lists inside classes)
- Basic error handing (checking for 'None' values).
- Docstrings for documentation.
